# AI-Generated Code and Dependency Risk Research Pilot



## Question
How similar are the dependency sets of apps generated by a single AI model from varied prompts, and how exposed would they be to a vulnerability in one common package?



## Plan
1. Choose one model and record its name and version
2. Generate a small set of projects (about 5-10) from varied prompts, saving each prompt.
3. Record each project's dependencies.
4. Compare overlap across projects and check the most common packages against public vulnerability data.


# Limitations
Small sample, one model, prompts created and chosen by me. This is a pilot and not a finished study.
